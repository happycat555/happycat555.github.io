## 发布文章

在 `_posts` 目录创建 `YYYY-MM-DD-英文短名.md`，填写实际发布日期，然后提交到 `main`。GitHub Pages 会自动发布。

```yaml
---
layout: post
title: "文章标题"
date: 2026-10-08
categories: [编程基础, 类型系统与参数传递]
tags: [TypeScript, JavaScript, "C#", 参数传递]
excerpt: "一句话说明这篇文章的内容。"
---
```

在 YAML 信息下方用 Markdown 写正文。日期不要设置在未来。

## 分类和标签

`categories` 是文章在目录中的位置，最多填写两项：第一项为一级分类，第二项为二级分类。只有一级分类时，例如 `categories: [随笔]`，文章直接展示在该分类下。没有分类的文章会进入“未分类”。不要用分类字段列出多个平行主题；平行主题应使用 `tags`。

现有目录：

- 编程基础
  - 基础知识地图
  - 类型系统与参数传递
- 随笔

新增文章时沿用合适分类；出现新主题后再增加新分类。目录、分类数量和标签筛选都从文章信息自动生成，无需手工添加链接。

`tags` 可以填写多个关键词，例如语言、框架和知识点。建议统一大小写，C# 使用 `"C#"`。

文章固定使用 `/posts/英文短名/` 地址，修改分类不会改变文章地址，也不会改变个人批注对应的文章。请尽量不要重命名已发布文章的英文短名。

## 个人批注

所有文章默认支持选择文字添加批注。“我的批注”汇总当前浏览器的文章批注，支持筛选、编辑、回收站和备份。批注保存在浏览器本地，不自动跨设备同步；换设备前请导出备份。
