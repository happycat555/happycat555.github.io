欢迎来到 HappyCat 的博客。这是博客的第一篇文章，也是一个新的开始：把学习过程、技术实践和生活里的小发现，慢慢整理成文字。

## 从小处开始记录

一篇文章不必很长。一个刚解决的问题、一段值得保存的代码、一本书里的启发，都可以成为写作的起点。

## 如何发布下一篇文章

1. 打开 [博客仓库](https://github.com/happycat555/happycat555.github.io)。
2. 点击 **Add file → Create new file**。
3. 文件名填写 `_posts/年-月-日-英文短名.md`，例如 `_posts/2026-10-07-learning-notes.md`。
4. 参照下面的格式填写内容，将标题和日期改为自己的文章信息。
5. 点击 **Commit changes**，提交到 `main` 分支。等待 GitHub Pages 部署完成，文章就会出现在首页。

```markdown
---
layout: post
title: "我的学习笔记"
date: 2026-10-07 09:00:00 +0800
categories: 学习
---

这里写文章摘要。

## 今天学到了什么

这里写正文，可以添加列表、链接、图片和代码。
```

文章日期不要设置在未来。修改现有文章时，打开对应文件，点击编辑按钮，修改后提交即可。
